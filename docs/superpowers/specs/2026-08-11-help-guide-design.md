# 使用说明（嵌入 Tab）设计文档

日期：2026-08-11
状态：已确认方向，待用户审阅

## 背景与目标

Roleplay Hub 需要一个「使用说明」功能，帮助新用户快速上手。经与用户确认：

- **内容形态**：简短上手指南（几百字至一两千字，读完即走，不反复查阅）
- **使用场景**：线上部署（pinme）与本地 `file://` 直接打开并存，离线可访问
- **覆盖范围**：仅主应用 `index.html`，不含角色卡工坊 `character/index.html`
- **内容撰写**：用户提供功能点素材，由开发者组织为 Markdown 初稿，用户审改

## 决策：嵌入 Tab 而非外链

| 维度 | 嵌入 Tab | 外链跳转浏览器 |
|---|---|---|
| 离线可用 | ✅ 本地 `file://` 可看 | ❌ 离线大概率打不开 |
| 依赖成本 | ✅ marked/DOMPurify 已在加载，零新增 | 需额外维护独立文档站点 |
| 用户留存 | ✅ 不离开应用 | 跳走后可能不回来 |
| 维护 | ✅ 内容随仓库同步部署 | 内容分散、多套部署 |
| 适用条件 | 简短指南 + 离线场景 | 长文档 + 纯线上 + 需 SEO |

当前需求（简短 + 离线）三项中两项直接否定外链方案，故选择**嵌入 Tab**。

## 设计

### 1. 内容存放：`assets/js/help-content.js`

- 新增文件，暴露 `window.RPHubHelpContent`（Markdown 模板字符串）
- **不能**用运行时 `fetch()` 本地 `.md` 文件：`file://` 协议下浏览器 CORS 拦截本地请求
- 因此内容必须嵌入 JS 源码，随应用一起加载
- 独立文件而非塞入 app.js：app.js 已约 1.2 万行，内容独立便于维护
- 在 `index.html` 脚本加载顺序中插入：`default-cards.js` 之后、`app.js` 之前（`help-content.js` 只暴露字符串，无依赖）

### 2. 入口与视图

- 侧边栏新增「使用说明」按钮，点击设置 `currentView = 'help'`
- 命名用 `help`，避免与现有 `usage`（Token 统计）视图混淆
- 主内容区新增 `<div v-if="currentView === 'help'">` 区块：
  - 顶部标题
  - `renderMarkdown(RPHubHelpContent, 'assistant', true)` 渲染
  - `.markdown-body` 现有样式 + 滚动容器（`overflow-y-auto`）
- 复用现有模式：与更新公告弹窗（index.html:3635-3659）同构——Markdown 字符串 + `renderMarkdown()` + `.markdown-body`

### 3. app.js 改动（最小化）

- 引入 `RPHubHelpContent`（window 全局读取）
- `setup()` 返回 `currentView`（已存在，无新增）
- 无需注册新组件、无需新依赖

### 4. 内容结构（草案大纲）

1. **快速开始**：导入角色卡 → 开始对话
2. **核心功能一览**：记忆系统、角色卡生成、UI 模板、设置项说明
3. **常见问题**
4. **数据存储说明**：localforage/IndexedDB，数据在本地浏览器内

具体章节以用户提供的素材为准，初稿由开发者组织，用户审改。

## 非目标（YAGNI）

- ❌ 不做独立文档站点/外链
- ❌ 不做首次启动引导弹窗（现有更新公告弹窗已承担通知职责）
- ❌ 不做全文搜索/目录锚点导航（简短指南不需要）
- ❌ 不覆盖角色卡工坊（未加载 marked，范围外）
- ❌ 不做多语言

## 验证方式

- 浏览器直接打开 `index.html`：`file://` 下说明可完整渲染（验证 CORS 约束规避生效）
- 侧边栏入口可切换视图、返回原视图状态不丢失
- Markdown 渲染无 XSS 风险（复用 DOMPurify 清理链路）
- 新增脚本不破坏既有加载顺序（无依赖报错）
